I'm Joseph, a full-stack developer from Brazil. I like owning a feature from the database to the last frame of its animation: TypeScript on both ends, React or Vue in front, Node or Laravel behind, and lately a lot of TanStack Start on Cloudflare Workers. On the side I build things that are mostly an excuse to make the browser do 3D, like a [Van Gogh gallery](https://github.com/dev-kohako/van-gogh-universe) and an [atlas of 204 celestial bodies](https://github.com/dev-kohako/kwk-stars).

<summary><sub>How this page is made</sub></summary>
<br>

Every image on this page is an SVG drawn by [a small Node script](scripts/build.mjs) with no dependencies. A [GitHub Action](.github/workflows/profile.yml) runs it once a day against the GraphQL API, so the crystals, the streaks, the repo counts in the periodic table and the stars on each project stay current. The words and the element list live in [`profile.config.mjs`](profile.config.mjs).

</details>
